# 🌦️ RPL Weather ETL Pipeline

ETL-пайплайн для сбора, обработки и анализа данных о погоде на матчах Российской Премьер-Лиги сезона 2024/2025. Проект включает извлечение данных о матчах и погодных условиях, их очистку, трансформацию, загрузку в PostgreSQL и визуальный анализ.

## ✨ Возможности
- 📥 **Извлечение данных**: загрузка расписания матчей РПЛ (JSON) и погодных данных (CSV).
- 🧹 **Очистка данных**: обработка пропусков, нормализация форматов, валидация.
- 🔄 **Трансформация**: объединение данных, расчёт дополнительных метрик (сезон, температура).
- 💾 **Загрузка в БД**: сохранение обработанных данных в PostgreSQL.
- 📊 **Визуализация**: построение графиков температуры и распределения погодных условий.
- 📈 **Аналитика**: SQL-запросы для анализа данных (средняя температура по сезонам, топ погодных условий).

## 🛠️ Требования
- Python 3.10+
- PostgreSQL 12+
- pip

## 📦 Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/pgruzdev/rpl-weather-etl.git
cd rpl-weather-etl
```

2. **Создайте и активируйте виртуальное окружение:**
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate
```

3. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

## ⚙️ Настройка базы данных

1. **Создайте файл конфигурации:**
```bash
cp .env.example .env
```

2. **Заполните `.env` данными вашей БД:**
```env
DB_USER=your_username
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=rpl_weather_db
```

3. **Создайте базу данных в PostgreSQL:**
```sql
CREATE DATABASE rpl_weather_db;
```

## 🚀 Запуск пайплайна
```bash
# 1. Извлечение сырых данных о матчах из API Football
python src/extract_matches.py

# 2. Трансформация JSON-матчей в структурированный CSV
python src/transform_matches.py

# 3. Извлечение данных о погоде (на основе полученного CSV с матчами)
python src/extract_weather.py

# 4. Объединение данных о матчах и погоде в один датасет + расчет сезонов
python src/merge_data.py

# 5. Загрузка финального датасета в PostgreSQL
python src/load_to_db.py

# 6. Аналитика и генерация графиков
python src/analytics.py
```

## 📓 Jupyter Notebook
Для интерактивного анализа и пошагового выполнения запросов:
```bash
jupyter notebook src/analytics.ipynb
```

## 📊 Результаты анализа
Скрипт `analytics.py` выводит в консоль отформатированные таблицы и сохраняет графики в папку `plots/`:
- `average_season_temp.png` — график средней температуры по временам года
- `weather_conditions_share.png` — доля различных погодных условий в матчах
